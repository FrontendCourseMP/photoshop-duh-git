# Photoshop Web

Учебный веб-редактор растровых изображений. Демонстрационный проект
в рамках лабораторных работ 1–5.

## Демо

**https://duh-git.github.io/**

(развёрнуто на GitHub Pages)

## Запуск локально

Проект — статическая веб-страница без сборки. ES-модули не работают
по `file://`, поэтому нужен HTTP-сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

Затем открыть <http://localhost:8000>.

## Возможности

### Форматы
- **PNG / JPEG** — растровые изображения (через `createImageBitmap`);
- **GB7 (GrayBit-7)** — собственный формат: 7 бит/пиксель grayscale
  + опциональный 1-битный alpha-канал (маска).

### Открытие / экспорт
- Кнопка «Открыть» + drag & drop.
- Экспорт в PNG, JPEG, GB7.
- Для GB7 сохраняются «сырые» 7-битные значения и маска.

### Зум и панорамирование
- Диапазон масштаба **12 %–300 %**.
- Панель в футере: range, числовое значение, dropdown пресетов.
- Ctrl+колесо, Ctrl+0 (fit), Ctrl+1 (100 %), Ctrl+±.
- При загрузке автоматический fit с отступом ≥ 50 px.
- Инструмент «Перемещение» (V): панорамирование холста.

### Каналы
- Панель каналов с миниатюрами (grayscale).
- Включение/выключение отдельных каналов — мгновенная перерисовка холста.
- Для GB7 с маской — отдельный Alpha-канал, синхронизированный
  с чекбоксом «Показывать маску».

### Пипетка
- Читает пиксель **из оригинала** (не из холста) — независимо от
  выключенных каналов.
- Корректно работает при любом зуме.
- Показывает X, Y, R, G, B, A и CIELAB (D65).

### Уровни (Levels)
- **Плавающее окно** (Ctrl+L).
- Гистограмма выбранного канала (Master / R / G / B / A; для GB7 — Master / Gray / A).
- Логарифмическая / линейная шкала.
- Слайдеры Input Levels: чёрная точка, гамма, белая точка.
- Предпросмотр в реальном времени.
- Параметры хранятся отдельно по каналам.
- Кнопки «Сброс / Отмена / Применить».

### Масштабирование (Resize)
- Модальное окно с полями ширины и высоты.
- Единицы: проценты / пиксели.
- Чекбокс «Сохранять пропорции».
- Два **собственных** метода интерполяции (без `drawImage`):
  * **ближайший сосед** — быстрый, сохраняет резкие границы;
  * **билинейная** — плавные переходы (по умолчанию).
- Архитектура методов — через реестр (`core/interpolation.js`),
  новый метод добавляется одной функцией `registerInterpolationMethod`.
- Для GB7 сохраняются 7-битные пиксели и бинарная маска.
- Валидация с предупреждением при превышении безопасного числа пикселей.

### Фильтрация (Filter)
- **Плавающее окно** — результат виден на холсте.
- Свёртка 3×3 с ядром.
- **Шесть пресетов**: identity, sharpen, gaussian 3×3, box blur,
  Прюитт X, Прюитт Y.
- Сетка 3×3 для ручного ввода коэффициентов.
- **Каналы**: Master / R / G / B / A (для GB7 — Master / Gray / A).
- **Edge handling**: чёрный / белый / копирование (padding).
- Предпросмотр, сброс, отмена, применение.
- **Web Worker** для расчёта — интерфейс не блокируется на больших изображениях.

## Принципы

- **Оригинал никогда не мутируется.** `rawData` в `canvasView` —
  источник правды. Видимое изображение собирается функциями
  `buildVisibleImageData` / `applyLevels` / `filterImageData` на каждой
  перерисовке.
- **Предпросмотр не трогает оригинал.** При открытии инструментов
  «Уровни» и «Фильтр» делается снимок `baseImageData`, все промежуточные
  результаты живут в `canvasView.previewData`. Фиксация результата
  (`Apply`) — единственное место, где оригинал заменяется.
- **Один канал — два представления.** Alpha-канал присутствует и в
  панели каналов, и в панели масок (чекбокс), синхронизация идёт через
  `canvasView.enabledChannels`.
- **CIELAB считается от sRGB.** Alpha не влияет на цветовые координаты.
- **Интерполяция и свёртка — собственные.** В `core/interpolation.js`
  и `core/convolution.js` нет вызовов `drawImage` для изменения размера
  или фильтрации.
- **Тяжёлые расчёты — в Web Worker.** Фильтрация вынесена в отдельный
  поток, UI остаётся отзывчивым. При недоступности воркера — fallback
  на синхронный расчёт.
